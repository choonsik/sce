HTML 작업본을 바로 호스팅하고 테스트할 수 있는 공간입니다.

📌 사용 방법

  1. 작업본 교체 / 추가: 이 index.html 파일을 본인의 작업본으로 덮어쓰거나, 새로운 폴더(예: work1/index.html)를 만들어 추가하세요.
  2. 푸시: git add . && git commit -m "update" && git push 명령어로 푸시합니다.
  3. 실시간 확인: GitHub Pages 설정 후 약 1분 뒤에 바로 웹에서 확인 가능합니다.
